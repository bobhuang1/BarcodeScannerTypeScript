This sample application connects to your barcode / RFID scanner over Bluetooth Low Energy and displays the data it scans.

What it collects

Everything happens on-device. The application does not collect, send or store any personal data. Scanned content is only kept in memory during the current session so it can be shown on the screen.

Local preferences

A few options (vibration, opening URLs, debug log, input height) are stored locally on the device. You can clear them at any time by removing the application.

No analytics

There is no analytics, no crash reporting and no advertising SDK in this sample.
